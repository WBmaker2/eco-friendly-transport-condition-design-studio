# 학습 이미지 잘림 개선 및 프로젝트 전반 점검 계획

- 점검일: 2026-08-17
- 대상 사용자: 초등 3~4학년 학생
- 점검 범위: 튜토리얼, 할 일 카드, 할 일 상세, 조건 확인, 조건 변경, 수레 미리보기, 반응형 화면

## 발견한 문제

첨부 화면에서 `mission-classroom-supplies.webp`의 위아래가 잘려 수레의 바퀴와 아래쪽 그림이 보이지 않았다. 원인은 학습 그림에 고정된 높이와 `object-fit: cover`가 함께 적용된 것이다. 같은 규칙이 튜토리얼·할 일 상세·조건 변경 그림과 할 일 카드 썸네일에도 적용되어, 정사각형 생성 이미지의 중요한 부분이 화면 밖으로 밀릴 수 있다.

## 개선 방향

1. 학습 맥락을 설명하는 큰 그림은 원본 비율을 지키고 전체가 보이도록 `contain`으로 표시한다.
2. 그림을 담는 상자에는 안정적인 반응형 비율과 배경색을 주어, 정사각형 그림도 잘리지 않고 자연스럽게 보이게 한다.
3. 할 일 카드 썸네일도 같은 원칙을 적용하되 카드 높이가 지나치게 커지지 않도록 4:3 영역 안에 전체 그림을 맞춘다.
4. 수레 미리보기는 원본 1:1 비율을 유지하고, 작은 화면에서도 좌우가 잘리지 않도록 `height: auto`를 명시한다.
5. 이미지 표시 규칙을 회귀 검사로 기록하고, 타입 검사·테스트·정적 Pages 빌드와 모바일/데스크톱 화면을 다시 확인한다.

## 구현 예정 파일

- `app/globals.css`: 학습 그림, 할 일 카드 썸네일, 수레 미리보기의 비율·맞춤 방식 수정
- `tests/content-validator.test.ts`: 생성 이미지가 잘림 방지 규칙을 사용한다는 회귀 검사 추가
- `app/transport/Dialogs.tsx`: 업데이트 내역에 이번 개선 기록 추가

## 완료 기준

- 생성 이미지 7개가 큰 그림·카드·미리보기 어디에서도 잘리지 않는다.
- 320px 안팎의 모바일 폭과 데스크톱 폭에서 가로 넘침이 없다.
- 이미지가 좁은 영역에 들어갈 때도 대체 문구와 캡션은 그대로 제공된다.
- 타입 검사, 전체 테스트, 린트, Pages 빌드가 통과한다.

## 구현 결과

- `learning-visual`, `mission-card`, `prototype-image`의 그림 맞춤 방식을 `contain`으로 바꾸고, 원본 비율·중앙 정렬·연한 배경색을 적용했다.
- 큰 그림은 3:2 반응형 영역, 할 일 카드는 16:9 썸네일 영역, 수레 미리보기는 1:1 영역을 사용해 정사각형 그림도 전체가 보이게 했다.
- 모바일 미디어 규칙에 남아 있던 고정 높이도 제거했다.
- `tests/content-validator.test.ts`에 그림 잘림 방지 CSS 회귀 검사를 추가했다.
- 업데이트 내역에 `2026-08-17 · v0.4.2`를 추가했다.
- 타입 검사, 22개 테스트, 린트, Pages 빌드와 `git diff --check`를 통과했다. 린트에는 기존 `<img>` 최적화 권고 경고 3건만 남아 있다.

- 로컬 개발 서버와 정적 Pages 빌드는 정상적으로 시작·완료됐다.
