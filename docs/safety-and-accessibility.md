# 안전·접근성 점검

- 모든 임무는 가상 학교 안의 무인 물품 수송으로 한정합니다.
- 결과는 교육용 조건 비교이며 실제 제작·운전 안전을 보증하지 않습니다.
- 부품 선택은 의미 있는 `fieldset`/`legend`와 라디오 카드로 제공됩니다.
- 시제품 SVG에는 선택 부품을 읽을 수 있는 HTML 목록을 함께 제공합니다.
- 조건 결과는 색뿐 아니라 `잘 맞음`, `일부 맞음`, `다시 설계` 문구로 제공합니다.
- 360px부터 단일 열로 전환하며, 작은 화면에서는 실행 조작대가 화면 하단에 머뭅니다.
- 움직임 줄이기 환경에서는 모든 전환을 제거합니다.
