# 학습용 이미지 생성·삽입 계획

작성일: 2026-08-16

## 목표

초등 3~4학년 학생이 `짐·거리·길·움직이는 힘` 조건을 한눈에 이해할 수 있도록, 기존의 수레 SVG 미리보기와 텍스트 중심 미션 화면을 생성형 학습 일러스트로 보강한다. 생성된 이미지는 모두 프로젝트의 `public/learning` 아래에 저장하고 실제 화면에서 사용한다.

## 현재 확인 결과

- 프로젝트의 주요 학습 그림은 `app/transport/PrototypePreview.tsx`의 동적 SVG 1개이다.
- 미션 카드와 조건 카드는 텍스트만 보여 주므로, 초등 3~4학년에게는 장면을 떠올리는 데 도움이 부족하다.
- `public`의 favicon·기본 아이콘 SVG는 학습 설명용 이미지가 아니므로 생성 대상에서 제외한다.

## 공통 이미지 기준

- `scientific-educational`와 `illustration-story` 사이의 어린이용 학습 일러스트 스타일을 사용한다.
- 글자·숫자·로고는 이미지 안에 넣지 않는다. 설명은 HTML 텍스트와 접근성 대체 문구로 제공한다.
- 친환경 색감(짙은 초록, 잎 초록, 따뜻한 노랑, 종이색)을 사용한다.
- 실제 수레의 안전을 보장하는 사진처럼 보이지 않도록, 단순하고 부드러운 그림으로 만든다.
- 위험한 도로, 자동차 교통, 얼굴 클로즈업, 브랜드·워터마크는 제외한다.

## 구현 순서

1. 생성형 이미지 7개를 각각 생성하고 시각적으로 검토한다.
2. 선택한 결과를 `public/learning`에 버전 관리 가능한 파일명으로 저장한다.
3. 미션 데이터에 이미지 경로와 대체 문구를 연결한다.
4. 튜토리얼, 미션 카드, 조건 변화 화면에 이미지를 삽입한다.
5. 수레 미리보기는 생성 이미지로 교체하되, 선택 부품 목록과 화면 읽기용 설명은 유지한다.
6. 단위 테스트·타입 검사·린트·빌드와 모바일 화면 확인을 실행한다.
7. 업데이트 내역에 이미지 생성·삽입 날짜와 변경 내용을 추가한다.

## 구현 결과

- 7개 이미지를 이미지 생성 모델의 기본 생성 모드로 만들고, 웹 전달량을 줄이기 위해 900px 기준 WebP로 변환했다.
- `public/learning`에 미션 5개, 전체 학습 장면 1개, 수레 미리보기 1개를 저장했다.
- 미션 카드·미션 상세·조건 확인·조건 변화·짧은 연습 화면에 생성 이미지를 연결했다.
- 기존 동적 수레 SVG는 생성된 `cart-prototype.webp`로 교체하고, 선택 부품 목록과 화면 읽기용 설명은 유지했다.
- 업데이트 내역에 `2026-08-16 · v0.4.0`을 추가했다.
- 타입 검사, 21개 테스트, 린트, 프로덕션 빌드가 완료됐다. 린트에는 `<img>` 사용에 대한 기존 Next 최적화 권고 경고 3건만 남아 있다.
