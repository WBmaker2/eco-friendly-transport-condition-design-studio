# 친환경 수송 조건 설계소

초등 5~6학년이 가상 학교 안의 물품 수송 임무를 읽고, 구조·적재부 / 이동부 / 동력·에너지부 / 조향·제동부를 조합해 보는 서버 없는 학습 웹앱입니다.

## 학습 흐름

조건 확인 → 네 부품 선택 → 조건별 첫 시험 → 개선할 조건과 지킬 장점 선택 → 한 부품만 변경 → 같은 조건에서 재시험 → 절충 비교서 완성 순서로 진행합니다. 결과는 총점 없이 짐·거리·길·안정성·에너지의 다섯 조건을 나란히 보여 줍니다.

전기·태양광·사람의 힘은 고정된 친환경 순위가 아닙니다. 앱은 운행 중, 에너지 마련, 재료·배터리 조건을 분리해 보여 줍니다.

## 실행과 검증

```bash
npm run dev
npm run test
npm run typecheck
npm run lint
npm run build
```

## 안전·개인정보 경계

- 실제 차량의 성능, 적재량, 안전을 보증하지 않는 교육용 디지털 시제품입니다.
- 실제 탑승·주행·배터리 분해·개조·충전기 변경을 안내하지 않습니다.
- 이름, 위치, 사진, 음성, 자유 입력을 수집하지 않으며 설계는 브라우저에 저장되지 않습니다.
- 외부 API, 생성형 AI, 분석·광고·추적 기능을 사용하지 않습니다.
